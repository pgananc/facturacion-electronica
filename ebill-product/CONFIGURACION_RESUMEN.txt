🛠️ TAREAS DE MAVEN DISPONIBLES
══════════════════════════════════════════════════════════════════════════════

Ctrl/Cmd + Shift + P → "Tasks: Run Task" → Selecciona:

• maven: clean install              ← Compilar e instalar
• maven: clean package              ← Empaquetar JAR
• maven: compile                    ← Solo compilar
• maven: test                       ← Ejecutar tests
• maven: spring-boot:run (localhost) ← Ejecutar (DEFAULT: Ctrl+Shift+B)
• maven: dependency:tree            ← Ver dependencias
• maven: clean                      ← Limpiar proyecto

🐛 TROUBLESHOOTING
══════════════════════════════════════════════════════════════════════════════

Problema: Puerto 8380 ocupado
Solución: $ lsof -ti:8380 | xargs kill -9

Problema: PostgreSQL no conecta
Solución: $ docker-compose down && docker-compose up -d

Problema: Errores de compilación
Solución: $ mvn clean install -U

Problema: Hot reload no funciona
Solución: Verifica que DevTools esté habilitado en pom.xml

Para más ayuda, revisa: README.md - Sección Troubleshooting
